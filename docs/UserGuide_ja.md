# オーロラ壁紙チェンジャー 使い方

[English](UserGuide.md) | 日本語

オーロラ壁紙チェンジャーは、モニターごとに指定したフォルダの画像を、決めた間隔で壁紙に設定するアプリです。
タスクトレイ（通知領域）に常駐して動きます。

## 1. はじめて使うとき

### 起動する

スタート メニューから「オーロラ壁紙チェンジャー」を起動します。
はじめて起動したときは、壁紙のフォルダがまだ無いため、設定画面が開きます。

設定画面を閉じても、アプリは終了しません。タスクトレイに常駐して、壁紙の切り替えを続けます。
アプリを終了するときは、タスクトレイのアイコンを右クリックして「終了」を選びます。

### タスクトレイのアイコンを見つける

アイコンは、タスクバーの右端（時計の近く）に表示されます。
見当たらないときは、タスクバーの「^」（隠れているインジケーター）を押すと、その中にあります。

いつも見えるようにするには、「^」の中のアイコンを、タスクバーの時計の近くへドラッグします。

- アイコンをダブルクリックすると、設定画面が開きます。
- アイコンを右クリックすると、メニューが開きます（「[3. タスクトレイのメニュー](#3-タスクトレイのメニュー)」）。
- アイコンにマウスを重ねると、切り替えの間隔や、一時停止中かどうかが表示されます。
- スタート メニューからもう一度起動しても、2 つ目は起動せず、設定画面が開きます。

### 壁紙のフォルダを設定する

1. 設定画面の左側の「モニター」で、設定するモニターを選びます。
   どれがどのモニターか分からないときは、「識別」を押すと、各モニターの画面に番号が出ます。
2. 「壁紙フォルダ」の「追加」を押し、壁紙にしたい画像のフォルダを選びます。
   フォルダは複数追加できます。フォルダの中のフォルダ（サブフォルダ）の画像も使うときは、「サブフォルダも検索する」をオンにします。
3. 表示レイアウト（1 枚表示・4 分割表示・16 分割表示・スパン）を選びます。
4. ほかのモニターも、同じように設定します。

使える画像は JPG / JPEG / PNG / BMP / WEBP です。
設定は、変えるとすぐに保存され、壁紙に反映されます。保存のボタンはありません。
設定画面の下の欄に、行った操作の結果が表示されます。

## 2. 設定画面

設定画面は、左側でモニターを選び、右側でそのモニターの設定をする作りです。
右側の項目のうち、「（全モニター共通）」と書かれたものは、どのモニターを選んでいても同じ設定です。

### モニター

| 項目 | 説明 |
| --- | --- |
| 識別 | 各モニターの画面に番号を表示します。左側の一覧の番号と同じです |
| モニターを再検出 | モニターの一覧を読み込み直します。モニターをつないだのに一覧に出ないときに使います |

モニターをつなぎ替えたときは、アプリが自動で気づき、一覧を更新します。
同じ型番のモニターをほかの端子につなぎ直した場合は、前の設定を引き継ぎます。

### 壁紙フォルダと表示レイアウト

| 表示レイアウト | 説明 |
| --- | --- |
| 1 枚表示 | 画面全体に 1 枚の画像を表示します |
| 4 分割表示 | 2 × 2 のマスに、4 枚の画像を同時に表示します |
| 16 分割表示 | 4 × 4 のマスに、16 枚の画像を同時に表示します |
| スパン | 複数のモニターにまたがって、1 枚の画像を表示します |

#### 1 枚表示

「表示方法」で、画像の収め方をモニターごとに選べます。

| 表示方法 | 説明 |
| --- | --- |
| Windows の設定に従う | 画像をそのまま壁紙にし、Windows の「個人用設定 > 背景」の調整方法で表示します（この Windows の設定は全モニター共通です） |
| 画面を埋める | 画面全体を覆うように拡大縮小し、はみ出した部分は中央で切り抜きます |
| 全体を表示 | 画像全体が画面に収まるように拡大縮小し、余白は黒にします。縦長の写真も切れずに表示できます |
| 引き伸ばす | 縦横比を変えて、画面いっぱいに引き伸ばします |
| 中央に表示 | 拡大縮小せずに中央に表示します。画面より大きい画像は中央を切り抜き、余白は黒にします |

#### 4 分割表示・16 分割表示

- フォルダは、左上・右上・左下・右下の 4 つに分けて設定できます。
  4 分割表示では各マスに、16 分割表示では 2 × 2 の 4 マスずつの区画に使います。どちらのレイアウトでも、同じ設定を使います。
- どのマスにもフォルダを設定していないときは、1 枚表示のフォルダから画像を選びます。
- 1 つでもフォルダを設定すると、フォルダの無いマスは画像を置かない「空きマス」になります。
- 「マスへの収め方」（マスを埋める・全体を表示）、マスの「間隔」と「間隔の色」、「空きマス・余白の色」も選べます。

#### スパン

- 「スパン」を選んだモニターどうしで、1 枚の画像を、各モニターの位置に合わせて切り分けて表示します。
- モニターの位置は、Windows の「設定 > システム > ディスプレイ」の配置に合わせます。モニターの縁の幅は考えません。
- フォルダ・サブフォルダの検索・画像の選び方・収め方（モニター全体を埋める・全体を表示）は、スパンを選んだモニターで共通です。

### プレビュー（現在の壁紙）

選んでいるモニターの、今の壁紙が表示されます。
「前の壁紙」「次の壁紙」で、そのモニターの壁紙だけを切り替えられます。

### 切替設定（全モニター共通）

| 項目 | 説明 |
| --- | --- |
| 切り替え間隔 | 壁紙を切り替える間隔です。1 分〜24 時間の間で、数と単位（分・時間）で指定します。はじめは 30 分です |
| 全画面表示のアプリの実行中は切り替えない | ゲームや動画の全画面表示、プレゼンテーションの間は切り替えを待ち、終わってから切り替えます |
| バッテリーで動作しているときは切り替えない | ノート PC などが電源につながっていない間は待ち、つないでから切り替えます |
| 全壁紙を更新 | 壁紙のフォルダを読み込み直して、全モニターの壁紙を選び直します。フォルダに画像を足したときに使います |

切り替えを待つ 2 つの設定は、はじめはオンです。手動の切り替え（「次の壁紙」など）は、オンでも待たずに切り替えます。

### ランダム設定

| 選び方 | 説明 |
| --- | --- |
| ランダム | フォルダの中の画像から、無作為に選びます |
| 順送り | ファイルの場所（パス）の順に、1 枚ずつ切り替えます |

### ほかのモニターの設定をコピー

モニターを買い替えたときなどに、前のモニター（今はつないでいないモニターも含みます）の
壁紙フォルダ・表示レイアウト・表示方法・選び方などを、選んでいるモニターにコピーします。

### 表示しない画像（全モニター共通）

タスクトレイのメニューの「この画像を表示しない」で指定した画像の一覧です。
「表示に戻す」で、また壁紙に使うようにできます。「場所を開く」で、画像のあるフォルダを開けます。

### 起動・言語・ログ

| 項目 | 説明 |
| --- | --- |
| Windows の起動時に自動的に開始する | オンにすると、Windows にサインインしたときにアプリが起動し、壁紙の切り替えを始めます。はじめはオフです |
| 表示言語（Language） | 日本語と英語を選べます。アプリを再起動すると反映されます |
| ログフォルダを開く | アプリの動作の記録（ログ）があるフォルダを開きます。ログは 14 日分残します |

### 設定の書き出し・読み込み

設定をファイルに書き出しておくと、ほかの PC や、アプリを入れ直したあとに読み込めます。

- 「設定を書き出す」で、今の設定を `.json` のファイルに保存します。
- 「設定を読み込む」で、書き出したファイルを選ぶと、確かめたうえで、今の設定をすべて置き換えます。
- 「Windows の起動時に自動的に開始する」と、壁紙の履歴（「前の壁紙」で戻れる画像）は含みません。
- 書き出したときとモニターが違う場合、同じ型番のモニターには自動で当てはめます。
  当てはまらなかったモニターの設定は、「ほかのモニターの設定をコピー」で使えます。

### アプリの情報

| 項目 | 説明 |
| --- | --- |
| このアプリについて | アプリのバージョンなどを表示します |
| ライセンス情報 | アプリが使用しているソフトウェアのライセンスを表示します |
| 使い方 | このページ（使い方ガイド）を Web ブラウザーで開きます |

## 3. タスクトレイのメニュー

タスクトレイのアイコンを右クリックすると、次のメニューが開きます。

| メニュー | 説明 |
| --- | --- |
| 次の壁紙 | 全モニターの壁紙を、次の画像に切り替えます |
| 前の壁紙 | 全モニターの壁紙を、1 つ前の画像に戻します |
| 全壁紙を更新 | 壁紙のフォルダを読み込み直して、全モニターの壁紙を選び直します |
| この画像を表示しない | 表示中の画像を選ぶと、その画像を壁紙に使わないようにし、別の画像に差し替えます（設定画面の「表示しない画像」で戻せます） |
| 画像の場所を開く | 表示中の画像を選ぶと、エクスプローラーでその画像を選んだ状態で開きます |
| 一時停止 / 再開 | 自動の切り替えを止めます。止めている間は「再開」になります |
| 設定 | 設定画面を開きます |
| 終了 | アプリを終了します |

分割表示のモニターでは、「この画像を表示しない」「画像の場所を開く」で、マスを選んでから画像を選びます。

## 4. 困ったとき

### 起動したのに何も表示されない

アプリはタスクトレイに常駐します。タスクバーの「^」の中にアイコンが無いか確かめてください（「[タスクトレイのアイコンを見つける](#タスクトレイのアイコンを見つける)」）。
スタート メニューからもう一度起動すると、設定画面が開きます。

### 壁紙が自動で切り替わらない

次のことを確かめてください。

- アイコンにマウスを重ねたときに「一時停止中」と出ていないか。出ている場合は、メニューの「再開」を選びます。
- 全画面表示のアプリ（ゲーム・動画・プレゼンテーションなど）を使っていないか。終わると切り替わります。
- ノート PC が電源につながっているか。バッテリーで動いている間は切り替えを待ちます。
  待たずに切り替えるには、「切替設定」の 2 つのチェックを外します。
- そのモニターに壁紙のフォルダがあり、フォルダに使える画像（JPG / JPEG / PNG / BMP / WEBP）があるか。

### WEBP の画像が表示されない

WEBP の画像を読むには、Windows の WebP の機能が必要です。
Windows 11 には入っています。Windows 10 では、Microsoft Store の「WebP 画像拡張機能」をインストールしてください。

### 「Windows の起動時に自動的に開始する」をオンにできない

Windows の設定やタスク マネージャーで自動起動を無効にした場合は、アプリからはオンにできません。
Windows の「設定 > アプリ > スタートアップ」で、「オーロラ壁紙チェンジャー」をオンにしてください。
会社の PC などで、管理者が自動起動を禁止している場合は、オンにできません。

### モニターを買い替えた・つなぎ替えた

同じ型番のモニターを別の端子につなぎ直した場合は、設定を自動で引き継ぎます。
新しいモニターには、「ほかのモニターの設定をコピー」で、前のモニターの設定をコピーできます。

### ほかの PC に設定を移したい

「[設定の書き出し・読み込み](#設定の書き出し読み込み)」を使います。

## 5. アンインストール

スタート メニューで「オーロラ壁紙チェンジャー」を右クリックし、「アンインストール」を選びます。

- 設定・壁紙の履歴・ログなど、アプリが PC に保存した情報も削除されます。
  あとで使う設定は、アンインストールの前に「設定を書き出す」で保存しておいてください。
- 壁紙は元の壁紙には戻りません。Windows の「設定 > 個人用設定 > 背景」で設定し直してください。
